# Vallentines-day

Site simples para o Dia dos Namorados criado por João Rafael.

Instruções rápidas:

- Este repositório contém `index.html` com todo o site.
- Para que as fotos apareçam, faça upload das imagens referenciadas no HTML (76999.jpg, 75747.jpg, 19349.jpg, 19355.jpg, 6081.jpg, 11840.jpg) para a raiz do repositório ou atualize os `src` para os caminhos corretos.
- Para publicar com GitHub Pages:
  1. Vá em Settings → Pages no GitHub do repositório.
  2. Em "Source", selecione a branch `main` e a pasta `/ (root)`.
  3. Salve — o site ficará disponível em alguns minutos.

Se quiser, eu posso também criar uma branch separada, adicionar as imagens e ativar Pages para você (preciso de permissão ou que me diga quais imagens enviar).
